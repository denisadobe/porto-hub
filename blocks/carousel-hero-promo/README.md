# carousel-hero-promo

Custom **carousel** block. Purpose: Full-width rotating promo banner with a photo background per slide, prev/next arrows, dot pagination and autoplay (pauses on hover/focus).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide. Cell 1: background image (only the image). Cell 2: heading (title), subtitle paragraph, CTA link, optional coupon as inline code (`PORTOPLUS`, rendered with a Copiar button), fine-print paragraphs after the CTA/coupon become the disclaimer.

## Supported variations

No variations.
